# Уютный Квадрат — сайт посуточной аренды квартир

Статический сайт на чистом **HTML / CSS / JS** (без сборки и фреймворков) с формой
онлайн-бронирования и **панелью менеджера** для просмотра и ведения броней.

Это редизайн по мотивам сайта уютныйквадрат.рф — свой дизайн (тёплый уютный
минимализм), своя вёрстка и логика.

## Структура

```
index.html          — публичный сайт (главная)
manager.html        — панель менеджера по броням (вход по PIN)
css/
  styles.css        — оформление сайта
  manager.css       — оформление панели
js/
  config.js         — НАСТРОЙКИ: контакты, почта, PIN менеджера
  data.js           — каталог квартир (добавляйте/меняйте объекты)
  main.js           — логика публичного сайта
  manager.js        — логика панели менеджера
assets/img/         — SVG-заглушки «фотографий» квартир (замените на реальные)
```

## Как запустить

Сборка не нужна. Любой статический сервер, например:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Панель менеджера: <http://localhost:8000/manager.html> (PIN по умолчанию — `2468`).

## Настройка

Всё меняется в **`js/config.js`**:

- `phone`, `email`, `address`, `telegram`, `whatsapp` — контакты на сайте;
- `web3formsKey` — куда отправлять заявки (см. ниже);
- `managerPin` — PIN для входа в панель менеджера.

Квартиры редактируются в **`js/data.js`** — массив объектов с ценой, площадью,
фото и описанием. Свои фотографии кладите в `assets/img/` и указывайте путь в поле `image`.

## Куда приходят заявки о бронировании

Сайт статический (без сервера), поэтому заявки отправляются напрямую из браузера.
Можно включить **несколько каналов сразу** — заявка уйдёт во все настроенные.
Все параметры задаются в `js/config.js`.

1. **Telegram** — заявка мгновенно приходит в чат менеджера. Настройка:
   1. В Telegram напишите **@BotFather** → `/newbot` → получите **токен** бота.
   2. Напишите своему боту любое сообщение (или добавьте его в нужную группу).
   3. Узнайте **chat_id**: напишите боту **@getmyid_bot**, либо откройте
      `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`.
   4. Впишите `telegramBotToken` и `telegramChatId` в `js/config.js`.

   > ⚠️ Токен виден в коде страницы (сайт статический). Заведите **отдельного** бота
   > только для заявок. При утечке токен можно отозвать/перевыпустить у @BotFather.
   > Для полного скрытия токена нужен серверный прокси (серверный вариант проекта).

2. **E-mail (Web3Forms)** — бесплатный сервис, заявка приходит на почту.
   Зарегистрируйтесь на <https://web3forms.com>, получите Access Key и вставьте его
   в `web3formsKey`.

3. **mailto (по умолчанию)** — если не настроен ни один канал выше, при отправке
   открывается почтовый клиент гостя с заполненным письмом на адрес из `email`.

Каждая заявка также сохраняется в браузере (localStorage) и появляется в панели менеджера.

## Панель менеджера

`manager.html` — список всех броней со сводкой, фильтрами по статусу, поиском,
сменой статуса (Новая → Подтверждена → Заселён / Отменена), ручным добавлением
брони и экспортом в CSV. Кнопка «Демо-данные» заполнит таблицу примерами.

> ⚠️ Важно: данные хранятся **локально в браузере** (localStorage). Этого достаточно
> для ведения броней на одном устройстве. Для общей многопользовательской базы,
> доступной с разных устройств, нужен серверный вариант (например, Node + SQLite
> или Supabase) — его можно подключить отдельно.

## Замена фотографий

В `assets/img/` лежат SVG-заглушки интерьеров (`apt-1.svg` … `apt-6.svg`, `hero.svg`).
Замените их на реальные фото (JPG/PNG/WebP) и обновите пути `image` в `js/data.js`
и `<img>` hero-секции в `index.html`.
